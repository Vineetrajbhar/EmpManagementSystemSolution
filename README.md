# 📌 Employee Management System (Web API) <br>

## 📖 Overview <br>
A RESTful Web API built using ASP.NET Core with 3-Tier Architecture. <br> 
Implements Repository Pattern, DTOs, and AutoMapper for clean, scalable, and maintainable code.<br>

---<br>

## 🚀 Features<br>
- CRUD Operations (Create, Read, Update, Delete)<br>
- 3-Tier Architecture (Presentation Layer (API),Business Logic Layer, Data Access Layer)<br>
- DTOs for data transfer<br>
- AutoMapper for object mapping<br>

---<br>

## 🛠️ Tech Stack<br>
- ASP.NET Core Web API<br>
- C#<br>
- Entity Framework Core<br>
- SQL Server<br>
- AutoMapper<br>

---<br>

## ⚙️ Setup<br>

1. Clone repo:<br>
git clone https://github.com/Vineetrajbhar/EmpManagementSystemSolution.git<br>

2. Configure DB:<br>
Update connection string in appsettings.json<br>

3. Run migration:<br>
update-database<br>

4. Run project:<br>
dotnet run<br>

---<br>

## 📡 API Endpoints<br>

GET     /api/employees        -> Get all employees  <br>
GET     /api/employees/{id}   -> Get employee by ID  <br>
POST    /api/employees        -> Create employee  <br>
PUT     /api/employees/{id}   -> Update employee  <br>
DELETE  /api/employees/{id}   -> Delete employee  <br>
